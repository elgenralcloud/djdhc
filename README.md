## About Me

I am Youssef Elgenral, a Software Engineering learner focused on building practical projects and developing a strong foundation across modern software development.

My interests include Cybersecurity, AI, AI Security, Web Development, and software engineering. I learn by building real projects, experimenting with technologies, documenting what I learn, and sharing knowledge through educational content.

My goal is to continuously improve as a developer while building useful software and developing a deeper understanding of secure and intelligent systems.
